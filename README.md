# 웹게임교실

## 온라인 주소

- 실행 사이트: https://jeonggunhwa.github.io/webgame-classroom/
- 소스 저장소: https://github.com/jeonggunhwa/webgame-classroom
- GitHub Pages는 `main` 브랜치의 루트에서 자동 배포합니다.
- 관리자 화면에서 바꾼 내용은 해당 브라우저에만 저장됩니다. 사이트 전체를 수정하려면 깃허브 소스를 수정해야 합니다.

바이브코딩으로 나만의 첫 웹게임을 만드는 중학교 1학년 대상 수업입니다. 학교명 없이 재사용할 수 있습니다.

## 구성

- 45분 × 3차시, 10분 휴식 × 2회, 총 155분
- 45장 웹슬라이드, 실습 프롬프트 8개, 퀴즈, 실습·휴식 타이머
- 별 잡기: 난이도·일시정지·재시작·키보드 조작을 지원하는 30초 반응 게임
- 강의 안내·자료실·질문·후기·관리자 편집·JSON 가져오기/내보내기

## 실행

- 웹 서버의 시작 파일: `index.html`
- 설치 없이 로컬에서 실행: `웹게임교실.html`
- 게임만 실행: `별잡기.html`
- 슬라이드 바로가기: `slides.html`
- 관리자 바로가기: `admin.html`

외부 라이브러리나 유료 API 없이 실행합니다. 별도의 빌드 단계가 필요하지 않은 정적 사이트입니다.

## 중요한 범위

**이 버전의 관리자 화면은 실제 인증이 아닙니다.** 사이트 이용자는 누구나 관리자 메뉴를 열 수 있습니다. 편집·질문·후기·진행 상태는 각 방문자의 브라우저에만 저장되며 서버나 다른 기기로 공유되지 않습니다. 관리자 변경도 다른 사람의 화면을 바꾸지 않습니다. 실제 수업의 다중 기기 동기화·관리자 인증은 별도 백엔드가 필요합니다.

실명·사진·계정 정보·비밀키를 입력하지 마세요. 공용 기기에서는 수업 후 브라우저 데이터를 정리하세요. 정적 사이트를 공개해도 학생의 로컬 기록이 이 저장소로 전송되지는 않습니다.

AI는 선생님이 승인한 별도 도구에서 사용하며, 이 앱에는 AI API가 연결되어 있지 않습니다.

## 수정

- `assets/content.js`: 강의 정보와 슬라이드
- `assets/style.css`: 디자인
- `assets/app.js`: 화면과 운영 흐름
- `assets/game-source.js`: 미리보기용 게임 원본 문자열
- `AGENTS.md`: 재사용 편집 규칙

소스를 수정하면 단일 HTML도 다시 생성해야 합니다. 관리자에서 편집한 내용은 파일이 아니라 해당 브라우저에 저장되므로 옮길 때는 강의 JSON을 내보내세요.

강의 화면과 설명을 참고해 독립적으로 재구성한 수업 자료이며 강사 원본 파일의 완전 복제본은 아닙니다. 자세한 실행·검증 범위는 `사용안내.md`, `검증기록.md`를 참고하세요.
